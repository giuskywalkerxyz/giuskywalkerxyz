I find security flaws in open-source software and report them through coordinated disclosure. I also do offensive security work for companies: web, API, Active Directory and AI/LLM assessments.

### Research

- **Local developer tooling.** Dev servers, devtools, MCP servers and local web UIs that any website or any host on the network can reach: DNS rebinding, CSRF against localhost, WebSockets without an Origin check.
- **Web application security.** Broken access control, SSRF, injection and authentication flaws in self-hosted apps.
- **Method.** Read the source, reproduce in an isolated lab, report privately with a working PoC and a suggested fix, then help verify the patch.

Advisories and CVEs are listed on [giullianoamaral.com](https://giullianoamaral.com) once they are public.
